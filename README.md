# Dashboard

Statická webová stránka (GitHub Pages) s dashboardem **Moje denní peníze**.

## Nasazení přes GitHub Pages

V repozitáři otevři **Settings → Pages** a nastav:

- **Source**: Deploy from a branch
- **Branch**: `main` (nebo `master`)
- **Folder**: `/(root)`

Pak GitHub vygeneruje URL, kde bude stránka dostupná.
